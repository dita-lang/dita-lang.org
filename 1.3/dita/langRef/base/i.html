<i>

The <i> element is typically used to apply italic highlighting to the content of the element. This element is part of the highlighting domain. Use this element only when a more semantically appropriate element is not available. For example, for specific items such as citations, use the <cite> element.

Note (non-normative):
Style sheets can be used to format the <i> element differently, just like any other element can be restyled. Thus, it is not the case that content in <i> elements will necessarily be italicized.
