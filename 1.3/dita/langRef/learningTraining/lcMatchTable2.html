<lcMatchTable2>

The <lcMatchTable2> element in an assessment interaction provides a format for matching items. This element replaces the <lcMatchTable> element in DITA 1.2.

Content model

<lcMatchingHeader2>?, <lcMatchingPair2>+

Contained by

<lcMatching2>

In order
  1. Optional <lcMatchingHeader2>
  2. One or more <lcMatchingPair2>

Contained by

  • <lcMatching2>

Inheritance

+ topic/div learningInteractionBase2-d/simpletable learning2-d/lcMatchTable2

Example

This section is non-normative.

See lcMatching2.

Attributes

The following attributes are available on this element: Universal attribute group and outputclass.
