<lcMatchingItem2>

The <lcMatchingItem2> element in an assessment interaction provides the content for the matching side of a matching pair of items in a match table interaction. This element replaces the <lcMatchingItem> element in DITA 1.2.

Content models

See appendix for information about this element in OASIS document type shells.

Inheritance
