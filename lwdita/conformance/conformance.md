# Conformance

-   **[Authoring tool conformance](../conformance/authoring-tool-conformance.md)**  
Specifies conformance requirements for Lightweight DITA \(LwDITA\) authoring tools.
-   **[Processing tool conformance](../conformance/processing-tool-conformance.md)**  
Specifies conformance requirements for tools that process Lightweight DITA content, typically for publishing or rendering, but possibly for other content-driven processes.
