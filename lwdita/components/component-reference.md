# Component reference

-   **[Lightweight DITA components, A to Z](../components/lwdita-components-a-to-z.md)**  
This topic contains links to all of the LwDITA components. They are listed in alphabetical order.
-   **[Basic topic components](../components/containers/basic-topic-components.md)**  
The generic topic structure is used for untyped topics.
-   **[Body components](../components/containers/body-components.md)**  
The body components support the most common types of content authoring for topics: paragraphs, lists, phrases, figures, and other common types of exhibits in a document.
-   **[Highlighting components](../components/containers/highlighting-components.md)**  
The highlighting components are used to apply formatting styles to text, such as bold and italic. Never use these elements when a semantically specific element is available. These elements are not intended for use by specializers; they are intended solely for use by authors when no semantically appropriate element is available and a formatting effect is required.
-   **[Emphasis components](../components/containers/emphasis-components.md)**  
The emphasis elements are used to emphasize text that is important or serious.
-   **[Map components](../components/containers/map-components.md)**  
Map components include the core components of LwDITA maps, such as key definition, key text, and topic reference.
-   **[Metadata components](../components/containers/metadata-components.md)**  
Metadata components include data and prolog components.
-   **[Multimedia components](../components/containers/multimedia-components.md)**  
The multimedia components are used to reference audio or video content.
-   **[Table components](../components/containers/table-components.md)**  
Table components include table, table header, table row, and table cell entry.
