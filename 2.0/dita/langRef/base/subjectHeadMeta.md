# `<subjectHeadMeta>`

The `<subjectHeadMeta>` element enables a navigation title and short description to be associated with a subject heading, for use if the subject scheme is rendered and displayed.

## Specialization hierarchy

The `<subjectHeadMeta>` element is specialized from `<topicmeta>`. It is defined in the subject scheme module.

## Content model

[`<titlealt>`](../content-models/../base/titlealt.md)\*, [`<shortdesc>`](../content-models/../base/shortdesc.md)?

Contained by

[`<subjectHead>`](../content-models/../base/subjectHead.md)

In order

1.  Zero or more [`<titlealt>`](../content-models/../base/titlealt.md)
2.  Optional [`<shortdesc>`](../content-models/../base/shortdesc.md)

Contained by

-   [`<subjectHead>`](../content-models/../base/subjectHead.md)

## Inheritance

- map/topicmeta subjectScheme/subjectHeadMeta

The `<subjectHeadMeta>` element is specialized from [`<topicmeta>`](../content-models/../base/topicmeta.md). It is defined in the subjectScheme module.
