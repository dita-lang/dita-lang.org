# Accessibility and translation

DITA has a number of built-in features that are intended to automate or enable content accessibility and translation. Together these features help content reach as many audiences as possible.

-   **[Accessibility](../../archSpec/base/accessibility.md)**  
DITA has markup and features that enable producing output that is accessible by all audiences.
-   **[Translation and localization](../../archSpec/base/translation.md)**  
DITA has markup that facilitates translation and localization. This markup includes the `@xml:lang` attribute, the `@dir` attribute, and the `@translate` attribute.
