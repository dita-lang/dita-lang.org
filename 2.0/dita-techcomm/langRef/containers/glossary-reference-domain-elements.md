# Glossary-reference domain elements

The glossary-reference domain is a map domain that specializes the `<glossref>` element for use with glossary topics.

-   **[glossref](../../langRef/technicalContent/glossref.md)**  
Glossary reference topic references are a convenience element for creating references to glossary topics. They have a required `@keys` attribute, which forces authors to create a key by which inline terms can reflect the glossary terms and become navigable links to the glossary definition.
